
# WebPulse ⚡

A lightweight Python website status checker that checks website availability, HTTP status codes, and response times.

## Features

- Check if a website is online or unreachable.
- Display HTTP status codes.
- Measure response time in milliseconds.
- Request timeout handling.
- Supports HTTP and HTTPS.
- Simple command-line interface.
- No external dependencies.

## Requirements

- Python 3.8+

## Installation

Clone the repository:

```bash
git clone https://github.com/USERNAME/WebPulse.git
cd WebPulse
```

## Usage

Run the tool:

```bash
python webpulse.py
```

Enter a website URL:

```text
Enter website URL: google.com
```

Type `exit` to quit.
